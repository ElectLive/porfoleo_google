# Norbert Aguilera — Portfolio (Google Style)

Personal portfolio built with Next.js 15, TypeScript, Tailwind CSS 4 and React 19, styled like Google search results. The app lives in [`mi-portfolio/`](mi-portfolio/README.md).

Live: [porfoleo-norbertaguilera.vercel.app/es](https://porfoleo-norbertaguilera.vercel.app/es)

## Quick start

```bash
cd mi-portfolio
npm install
npm run dev      # http://localhost:3000
```

Or with Docker, from the repository root:

```bash
cd mi-portfolio && docker-compose up --build
```

Full documentation, structure, tech stack and i18n notes: [mi-portfolio/README.md](mi-portfolio/README.md).

## Implemented

Home (Google results + knowledge panel), projects (6), technologies (37 filters), IA page, ES/EN/CA i18n, header/nav, CV PDFs and responsive layout. Dark-mode CSS variables exist but the toggle is not implemented yet.
